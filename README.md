## Overview

Arturia BeatStep Pro companion software extends the BeatStep Pro hardware with additional sequence editing, pattern management, and MIDI mapping capabilities for live performance.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Arturia Beat Step Pro** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Pattern Editor** | Visual step sequence editor with per-step pitch, velocity, and gate |
| **MIDI Map** | Comprehensive MIDI controller mapping for hardware and software |
| **Pattern Bank** | Store and recall pattern banks for live performance switching |
| **Sync** | MIDI clock and USB sync with tight timing for live and studio use |
